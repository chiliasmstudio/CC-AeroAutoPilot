# 懸停專用飛控設定記錄

## 目前安全設定

電腦端韌體採用 HOVER-ONLY 設定。保留高度保持、目前高度鎖定、懸停基準調整、自動校準與緊急停止。航點、航向、前進／後退與左右側推功能停用。

## 水平推力保護層

水平推力在三處歸零，避免舊狀態、舊客戶端或其他控制路徑重新啟動水平引擎：

1. 飛控迴圈每次更新都清除航點／航向旗標與水平油門，水平虛擬輸出固定為 0。
2. `outputToEngines()` 對 `FWD`、`BWD`、`LEFT`、`RIGHT` 再次硬性歸零；廣播封包也只會帶水平零推力。
3. 電腦本體六個紅石面固定輸出 0。四軸垂直升力仍透過 `FL`、`FR`、`BL`、`BR` 烏龜節點輸出。

FCC-CLI 在發出封包前拒絕航點、航向及水平推力命令。飛控 API 對航點／航向方法也採停用實作，確保觸控介面或舊客戶端不能繞過 CLI 保護。

## 維護與部署

- 修改電腦端行為時，依根目錄 `agent.md` 規定遞增 Computer Suite 版本並執行 `python bundle.py --bump-computer <patch|minor|major>`。
- `run.lua` 用於 All-In-One 模式；`fcc.lua` 用於 FCC 模式；兩者均需部署新版本。CLI 用戶端也需更新 `fcc-cli.lua` 才會在本機顯示停用指令訊息。
- 僅在遊戲中確認升力烏龜接線與實際懸停；建置檢查不能取代物理實測。電腦六面直連紅石的引擎會因安全設定保持關閉。
